ผู้ควบคุมข้อมูลมีที่ตั้งอยู่นอกสหภาพยุโรป เนื่องจากบริการนี้มุ่งไปยังบุคคลในเขตเศรษฐกิจยุโรป จึงใช้ข้อบังคับ GDPR เป็นมาตรฐาน

หลักการ

เว็บไซต์นี้เป็นหน้าข้อมูลแบบสแตติก ไม่มีบัญชีผู้ใช้ ไม่มีระบบแสดงความคิดเห็น และไม่มีแบบฟอร์มติดต่อ ไม่มีการใช้คุกกี้ ไม่มีบริการวิเคราะห์หรือติดตามผู้ใช้ และไม่มีเครือข่ายโฆษณา

โฮสติงและบันทึกของเซิร์ฟเวอร์

เว็บไซต์นี้ให้บริการผ่าน GitHub Pages ซึ่งเป็นบริการของ GitHub, Inc., 88 Colin P. Kelly Jr. Street, San Francisco, CA 94107, สหรัฐอเมริกา

เมื่อคุณเปิดหน้าเว็บ ผู้ให้บริการโฮสติงจะประมวลผลข้อมูลการเข้าถึงที่จำเป็นทางเทคนิค ซึ่งเบราว์เซอร์ของคุณส่งโดยอัตโนมัติ ได้แก่

  • หมายเลข IP ของอุปกรณ์ที่ร้องขอ
  • วันและเวลาที่เข้าถึง
  • ชื่อและ URL ของไฟล์ที่เรียกดู
  • ปริมาณข้อมูลที่ถ่ายโอนและสถานะการเรียกดู
  • หน้าที่อ้างอิงมา (referrer) หากมี
  • เบราว์เซอร์และระบบปฏิบัติการที่ใช้

วัตถุประสงค์คือการส่งมอบหน้าเว็บทางเทคนิค รวมถึงการรักษาเสถียรภาพและความปลอดภัย ฐานทางกฎหมายคือ Art. 6(1)(f) GDPR ซึ่งเป็นประโยชน์อันชอบธรรมในการดำเนินงานอย่างปลอดภัยและราบรื่น

เนื่องจาก GitHub มีที่ตั้งในสหรัฐอเมริกา จึงอาจมีการถ่ายโอนข้อมูลไปยังประเทศที่สาม GitHub ระบุว่าปฏิบัติตามข้อกำหนดของ GDPR ผ่านข้อตกลงตามสัญญาที่เกี่ยวข้อง

แบบอักษร

แบบอักษรที่ใช้ถูกส่งจากเซิร์ฟเวอร์นี้โดยตรง ไม่มีการเชื่อมต่อไปยัง Google Fonts หรือผู้ให้บริการภายนอกรายอื่น และไม่มีการส่งหมายเลข IP ไปยังบุคคลที่สาม

การติดต่อทางอีเมล

หากคุณติดต่อมาทางอีเมล ข้อมูลของคุณจะถูกประมวลผลเพื่อดำเนินการตามคำขอและคำถามที่เกี่ยวข้อง ฐานทางกฎหมายคือ Art. 6(1)(b) GDPR สำหรับคำขอก่อนทำสัญญา หรือ Art. 6(1)(f) GDPR ในกรณีอื่น ข้อมูลจะถูกลบเมื่อไม่จำเป็นอีกต่อไปและไม่มีข้อผูกพันทางกฎหมายให้เก็บรักษา

ลิงก์ภายนอก

เว็บไซต์นี้มีลิงก์ไปยังบริการภายนอก เช่น YouTube, LinkedIn และ aheadx.at ลิงก์เหล่านี้จะถูกเรียกใช้เมื่อคุณคลิกเท่านั้น ก่อนหน้านั้นไม่มีการส่งข้อมูลไปยังผู้ให้บริการดังกล่าว หลังจากคลิกแล้ว จะเป็นไปตามนโยบายความเป็นส่วนตัวของผู้ให้บริการนั้น

สิทธิของคุณ

ภายใต้เงื่อนไขทางกฎหมาย คุณมีสิทธิขอเข้าถึงข้อมูล ขอแก้ไข ขอลบ ขอจำกัดการประมวลผล ขอโอนย้ายข้อมูล และสิทธิคัดค้านการประมวลผล กรุณาติดต่อผ่านอีเมลที่ระบุไว้ข้างต้น

นอกจากนี้คุณมีสิทธิยื่นเรื่องร้องเรียนต่อหน่วยงานกำกับดูแล สำหรับประเทศออสเตรียคือ Austrian Data Protection Authority, Barichgasse 40 ถึง 42, 1030 Vienna
